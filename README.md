# 🩺 DocAppoint

A modern doctor appointment booking platform built with Next.js that allows users to find doctors, book appointments, and manage healthcare services through a responsive and user-friendly interface.

## 🌐 Live Demo

- **Live Site:** https://docappoint-liard.vercel.app/
- **Server:** https://docappoint-server-beta.vercel.app/

## 🚀 Features

- 🔐 Secure Authentication (JWT/Firebase)
- 👨‍⚕️ Browse Doctors by Specialty
- 📅 Book & Manage Appointments
- 👤 Role-Based Dashboard (Patient, Doctor, Admin)
- 💳 Online Payment Integration
- 📱 Fully Responsive Design

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/docappoint-client.git
```

Go to the project folder:

```bash
cd docappoint-client
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

## 🔑 Environment Variables

Create a `.env.local` file and add:

```env
NEXT_PUBLIC_API_URL=your_api_url
NEXT_PUBLIC_FIREBASE_API_KEY=your_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_domain
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
```
